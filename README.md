> 🌐 **在线玩**：https://zkd27712306.github.io/VoxelCraft

## 特性

- **单文件游戏**：所有游戏代码（HTML + CSS + JS）都在一个 HTML 里
- **CDN 加载引擎**：Three.js r160 从 CDN 拉取，**首次打开需要联网**，之后浏览器缓存可离线
- **程序化生成**：地形、生物群系、洞穴、矿脉、树木、村庄、纹理全部算法生成
- **无限世界**：区块按需加载/卸载，玩家周围动态渲染
- **完整光照**：天空光 + 方块光双通道传播，支持平滑光照和 AO
- **昼夜循环**：太阳、月亮、星空、云层、雾色随时间变化
- **生存机制**：生命、饥饿、氧气、摔落伤害、岩浆伤害、溺水、饥饿掉血
- **完整合成**：2×2 背包合成 + 3×3 工作台合成，30+ 配方
- **熔炉冶炼**：铁/金/玻璃/石头/熟肉/木炭，燃料系统
- **实体系统**：猪、牛、羊、鸡、村民、僵尸、骷髅、苦力怕、蜘蛛
- **载具**：可乘坐的船，能在水面快速航行、陆地上缓慢拖行
- **物理**：AABB 碰撞、自动上台阶、跳跃、游泳、飞行
- **存档**：localStorage 自动保存 + JSON 导入导出（方块、背包、熔炉、箱子）
- **移动端**：虚拟摇杆 + 触摸按钮，**三击丢弃**，点击切格
- **多人格视角**：第一人称 / 第三人称（背后 / 面前）

## 玩法

### 方块与工具

游戏包含 **30+ 种方块**，包括：

- **自然方块**：草、泥土、石头、沙子、砂砾、雪、仙人掌、原木、树叶
- **矿物**：煤、铁、金、钻石（按深度分布）
- **液体**：水（可游泳）、岩浆（发光，伤害）
- **功能方块**：工作台、熔炉、箱子、床、火把
- **建材**：木板、圆石、石砖、砖块、玻璃、干草块

**工具效率**：

| 工具 | 高效方块 | 掉落要求 |
|---|---|---|
| 镐 | 石头类 | 石头/矿石需要镐才有掉落 |
| 斧 | 木制品 | —— |
| 锹 | 泥土/沙子/雪 | —— |
| 剑 | 生物（提高伤害） | —— |

工具分木、石、铁三个等级，等级越高挖得越快、耐久越高。

### 合成配方

在 **2×2 背包** 或 **3×3 工作台** 摆放物品即可合成。

#### 基础

| 成品 | 配方 |

| 木棍 ×4 | 木板 ×2（竖排） |
| 工作台 | 木板 ×4 |
| 熔炉 | 圆石 ×8 |
| 火把 ×4 | 煤 / 木炭 ×1 + 木棍 ×1 |
| 箱子 | 木板 ×8 |
| 床 | 羊毛 ×3 + 木板 ×3 |

#### 工具

| 成品 | 配方 |
|---|---|
| 镐 | 材料 ×3（顶排）+ 木棍 ×2（中下） |

| 剑 | 材料 ×2（竖排）+ 木棍 ×1 |

材料可以是：木板 / 圆石 / 铁锭。

#### 方块与食物

| 成品 | 配方 |

### 熔炉冶炼

在熔炉中，**上方放原料，下方放燃料**。

| 原料 | 产物 |
|---|---|
| 铁矿石 | 铁锭 |
| 金矿石 | 金锭 |
| 沙子 | 玻璃 |
| 圆石 | 石头 |
| 原木 | 木炭 |
| 生猪排 / 生牛肉 / 生鸡肉 | 熟肉 |

**可作燃料**：煤、木炭、木板、原木、木棍。

### 箱子存储

27 格存储空间。左键拿起/放下整叠，右键放下一半/一个，Shift+左键快速移动。箱子内容会随存档保存。

### 床与睡觉

- 右键床可以跳过夜晚
- 只能在**夜间**睡觉
- 周围 12 格内有**敌对生物**时无法入睡
- 睡觉后天亮，恢复满生命

### 生物

| 生物 | 生命 | 掉落 |
|---|---|---|
| 猪 | 10 | 生猪排 |
| 牛 | 10 | 生牛肉、皮革 |
| 羊 | 8 | 羊毛、皮革 |
| 鸡 | 4 | 生鸡肉、羽毛 |
| 僵尸 | 20 | 皮革（白天会燃烧） |
| 骷髅 | 20 | 骨头、箭（远程攻击） |
| 苦力怕 | 20 | 火药（会爆炸） |
| 蜘蛛 | 16 | 线 |
| 村民 | 20 | —— |

**刷新规则**
- 敌对生物夜间或暗处刷新
- 白天敌对生物暴露在阳光下会着火
- 被动生物在草地/雪地白天刷新
- 村庄附近自动补充村民

### 村庄

世界生成时会在特定位置生成村庄，包含：
- 木板/圆石墙的房屋
- 玻璃窗户
- 火把照明
- 箱子（可能含战利品）
- 小农田

村民会在村庄范围内游荡。

### 船

木船是一种可乘坐的载具，能在水面快速航行，也能在陆地上缓慢拖动。

#### 合成

| 成品 | 配方 |
|---|---|
| 船 ×1 | 木板 ×5 |

在 3×3 工作台上摆放：

    P . P
    P P P
    . . .

（`P` = 木板，`.` = 空）

背包 2×2 合成格**放不下**这个配方，必须用工作台。

#### 放置

手持船，对着**水面或地面**按右键：

- 会沿视线方向落到 3 格远处
- 如果射线命中方块，则放在该方块相邻的空位
- 从落点往下找第一个非空气方块作为地面
- 若地面之上有连续的水，船会浮在水面最上一格
- 若没有水，船直接停在陆地表面

放置后船会轻微摇晃，等它落定即可右键登船。

#### 乘坐与操控

| 操作 | 键位 / 手势 |
|---|---|
| 登船 | 对着船按右键 |
| 前进 / 后退 | `W` / `S` |
| 左转 / 右转 | `A` / `D` |
| 下船 | `Shift` |

- 上船后玩家视角自动跟随船的朝向，移动键控制船，不控制人物
- 水面最高速度 **5.5 格/秒**
- 陆地最高速度 **2.2 格/秒**
- 岩浆里最高速度 **1.2 格/秒**
- 船在水里会自动浮到水面并保持稳定；离水后受重力下落

#### 物理

- 船体是**宽 1.5 × 高 0.5** 的 AABB，独立做 X / Z / Y 三轴碰撞
- 撞到方块会停下，不会穿墙
- 船掉进虚空会自动回到海平面，不会丢失
- 玩家下船时会尝试放到船旁边 1.4 格内的安全位置；
  都放不下就放在船正上方 1.2 格处

#### 摧毁与回收

- 船目前**不能用左键破坏**（只是载具）
- 乘坐时按 `Shift` 下船
- **船不随存档保存**：保存/重进世界后，之前放的船会消失

> 提示：想跨海去对岸、或沿河探索时，船比游泳快得多。
> 陆地拖行虽然慢，但可以把船"搬"过一段浅滩。

## 存档

### 自动保存

- 每 30 秒自动保存到浏览器 localStorage
- 关闭页面前自动保存
- 只保存**玩家改动过的方块**（不存整个世界的生成数据）

### 手动保存

暂停菜单 → **保存存档**。

### 导出/导入 JSON

- 暂停菜单 → **导出存档 JSON** → 下载 `.json` 文件
- 暂停菜单 → **导入存档 JSON** → 选择文件
- 标题界面也可以导出**本地已有存档**

### 存档内容

- 世界种子
- 玩家位置、朝向、生命、饥饿
- 背包物品（含耐久）
- 所有修改过的方块（坐标 + 方块 id）
- 熔炉内容（输入、燃料、输出、燃烧进度）
- 箱子内容

> **注意**：船、掉落物、生物**都不会**被保存。
> 重新进入世界后，之前放的船会消失。

### 清除数据

设置 → **清除所有数据…**：删除 localStorage、sessionStorage、IndexedDB、Cache Storage、Service Worker，然后自动刷新页面。

**此操作不可撤销。**

## 技术细节

### 架构

    Config       →  常量、速度、重力
    Textures     →  程序化生成 16×16 图集
    Blocks       →  方块定义表
    Noise        →  Perlin 噪声
    WorldGen     →  地形、生物群系、洞穴、矿脉、树木
    Village      →  村庄站点 + 建筑生成
    Chunk        →  区块数据（16×256×16）
    Light        →  天空光 + 方块光 BFS
    Mesher       →  面剔除 + AO + 平滑光照
    Renderer     →  Three.js + 自定义 ShaderMaterial
    Player       →  物理 + 碰撞 + 生存机制
    Interaction  →  射线检测 + 挖掘/放置
    Mob          →  生物 AI + 物理
    Boats        →  船实体 + 水面浮力 + 三轴碰撞
    UI           →  背包、工作台、熔炉、箱子
    Save         →  localStorage + JSON 导入导出
    Game         →  主循环、区块加载、事件绑定

### 关键实现

**世界表示**
- 区块大小 16×256×16 = 65536 个方块
- 方块 id 用 `Uint8Array` 存储，支持最多 256 种方块
- 线性索引：`x | (z << 4) | (y << 8)`

**光照系统**
- 天空光：从顶部竖直传播 + BFS 横向扩散
- 方块光：光源 BFS 传播
- 水面额外衰减 3 级，树叶 1 级
- 平滑光照：每个顶点采样 4 个角取平均
- 环境光遮蔽（AO）：按邻居遮挡程度映射到 4 级明暗

**网格生成**
- 面剔除：只生成暴露在空气中的面
- 4 个顶点/面（分不透明/镂空/水/岩浆 4 个 pass）
- 顶点属性：位置、UV、光照（天空/方块）、面明暗、波动标记（水）

**材质**
- 自定义 `ShaderMaterial`
- 顶点着色器处理水/岩浆波动
- 片元着色器合成纹理 × 光照 × 面明暗 × 雾

**船**
- 单个 `Boats` 模块管理所有船
- 船体使用与玩家一致的 AABB 碰撞，分 X / Z / Y 独立求解
- 浮力：在水里把 `pos.y` 缓动到 `floor(y) + 0.05`，`vel.y` 阻尼归零
- 陆地：`vel.y -= gravity * 0.6 * dt`，落到方块顶面
- 甲板几何：5 个 box 拼成（船底 + 两侧 + 前后挡板），UV 来自 `boat_wood` 图块
- 光照：船体每 0.4 秒采样一次 `sampleWorldLight` 更新顶点光

**性能优化**
- 分帧加载：每帧最多处理 N 个区块（时间预算 6ms）
- 近处优先：候选区块按距离排序
- 远处卸载：超出渲染距离 2.5 倍的区块直接销毁
- 粒子池：1200 个粒子复用，不动态分配
- 掉落物池：160 个上限
- 生物上限：42 个

## 已知限制

### 性能

- 渲染距离 12 区块时，低端设备可能卡顿
- 建议移动端使用 5~7 区块
- 大量掉落物 + 粒子会掉帧

### 玩法

- 没有红石、附魔、酿造
- 没有地狱、末地
- 没有村庄交易
- 没有存档分栏（一个浏览器只有一份存档）
- 没有多人
- **船只有一种（木船）**：没有矿车、没有鞍、没有动物骑乘

### 技术

- 世界高度固定 256（不能竖直扩展）
- 区块 16×16（不能改）
- 光照传播是单区块内的（跨区块边界有轻微断层）
- 存档大小随时间增长（所有方块改动都记录）
- **首次打开需要联网**（Three.js 从 CDN 加载）
- **船、掉落物、生物不进存档**：重进世界后会消失

## 常见问题

### Q: 打开后黑屏 / 卡在"正在生成世界"

**检查**
1. F12 看 console 有没有红色错误
2. 检查 WebGL 是否可用
3. **检查是否联网**：Three.js 从 CDN 加载，断网且没缓存过会失败
4. 尝试换浏览器

### Q: 提示 "无法载入 Three.js（本地与 CDN 均失败）"

**原因**：CDN 全部不可达。

**解决**：联网后刷新。

### Q: 鼠标点击画面没反应

**桌面**：需要先点击画面**锁定鼠标**（首次会提示）。按 `Esc` 会释放锁定，再点一下重新锁定。

**触屏**：无需锁定，直接操作。

### Q: 移动端打开没有虚拟摇杆

**检查**
1. 设置里"触屏控制"是不是"关"（改成"自动"或"开"）
2. 浏览器 UA 是否被判定为非移动端
3. URL 加 `?touch=1` 强制开启

### Q: 连点快捷栏不丢物品

**检查**
1. 快捷栏格子有物品吗？（空格不丢）
2. 是不是**在 400ms 内连续点了 3 次**？（间隔太久会重新计数）
3. 有没有中途点到别的格子？（换格会清零）
4. 打开 F12 看有没有报错

### Q: 存档丢了

**可能原因**
- 浏览器隐私模式（localStorage 在关闭标签后清除）
- 手动清了浏览器数据
- 换了浏览器 / 设备

**建议**：定期**导出 JSON** 备份。

### Q: FPS 很低

**优化**
1. 降低渲染距离（设置 → 渲染距离 → 5）
2. 关闭背景标签页
3. 降低屏幕分辨率 / 窗口大小
4. 清掉地面上的掉落物

### Q: 白天僵尸还在（没有燃烧）

**检查**
- 僵尸是否在**水下**？（水下不燃烧）
- 是否在**阴影**里？（有方块遮挡也不燃烧）
- 游戏内时间是否真的是白天？（按 `F3` 看"时间"）

### Q: 熔炉不冶炼

**检查**
1. 上方有没有放**原料**？
2. 下方有没有放**燃料**？
3. 燃料是否有效？（煤、木炭、木板、原木、木棍）
4. 产物格是否已满？

### Q: 村民不刷新

村民只会在**村庄附近**刷新。如果出生点附近没有村庄：
- 走到远处探索
- 或者用创造模式自己建造房屋（不刷村民）
- 或者导入一份村庄种子附近的存档

### Q: 船放不下去 / 放下就消失

**检查**
1. 是不是手持船？（背包里选中 `船`）
2. 射线前方 3 格内有没有地面或水面？
   - 船会沿视线落到 3 格远处，如果那里是虚空会落到海平面
3. 落点是方块内部？（船会尝试向下找地面，找不到就浮在海平面）

### Q: 上不了船

**检查**
1. 是不是**右键**船？（左键是攻击，不是上船）
2. 船是不是在岩浆里？岩浆里船速很慢，但仍可上
3. 是不是已经骑着船？先按 `Shift` 下船再上另一艘

### Q: 重进世界后船不见了

**原因**：船不在存档内容里。

**解决**：目前只能接受船不保存。
